Request: select resolution and windowed/fullscreen from the launcher because the game repeatedly starts at an unwanted resolution. ## Implemented result

Launcher 0.1.3 adds Settings > Display, Fullscreen/Windowed/Use game settings, a primary-display resolution list and Desktop resolution resolved on each launch. Save confirms persistence; pending choices are distinguished from saved ones, and Home links to the saved display summary. Choices can be saved during a running game for the next launch. They are stored in ignored local/launcher/settings.json without editing installed content, game preferences, personal saves or Windows display configuration. Invalid dimensions, extra arguments and unavailable resolutions fail before game launch.

The service reads Windows EnumDisplaySettingsW using the 220-byte DEVMODEW ABI and forwards a validated optional mode/resolution pair to SporeMP.NativeHost. The host constructs only the documented -w/-f and -r:WIDTHxHEIGHT game flags. Existing compatibility, payload and account-mode checks remain. No new SDK binding, injected display manipulation or gameplay mutation was added. The Release bridge remains byte-identical to the running M02 bridge.
