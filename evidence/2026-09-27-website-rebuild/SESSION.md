## Browser evidence and retained corrections

Both languages were measured at widths 1440, 1024, 768, 390 and 320 px, with no horizontal page overflow. Text enlargement to 200% was checked at 1440, 768, 390 and 320 px in both languages. The first enlargement pass exposed wrapping failures; flexible grid items, a wrapping header, scalable disclosure controls and narrower-screen release rows fixed them. A nested heading's inherited letter spacing was corrected in article navigation. The final 33-scenario pass includes keyboard Home/Arrow navigation, stage/language continuity, article language pairing, menu/Escape, FAQ/release disclosures, historical routes/anchors, reduced motion and no-JavaScript content.

The first Windows `npx` invocation of the multi-line browser harness failed to parse (exit 1). Invoking the same installed CLI entry point directly with Node resolved argument forwarding; this was not a site failure. An early stale browser reference was refreshed before subsequent actions. A combined background-preview command and a combined source-cleanup command were rejected before execution; separate explicit operations completed the intended work.

The first byte-for-byte publication check exposed line-ending differences between local Windows text and GitHub's Linux checkout. The site displayed the deployed stylesheet correctly, but local and deployed content-hash filenames differed. Build output is now normalized to LF, and all 39 published files match the local build exactly. The not-found page also uses absolute site URLs so that an unknown nested URL retains its styling and a valid home link; the actual live 404 case passed.

Original screenshots of the live English desktop, French mobile, five-stage explorer and article page were opened and visually inspected. Initial blank stage captures were taken before asynchronous image decoding; final screenshots were taken after image decoding and inspected with all five scenes visible. The new artwork was also inspected directly. Asset prompts and provenance are in `website/assets/credits.txt`.

Raw browser results, screenshots and HTTP checks are under ignored `local/site-redesign-2026-09-27/`. Public evidence contains only this reviewed report and hash lists. No private game capture, save, invitation, credential or account inventory was published.
