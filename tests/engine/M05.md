## Prerequisites

- Use the pinned original executable/content and SDK configuration recorded in M04. Build/test commands must never launch native gameplay automatically.
- Verify personal backup manifests and hashes. Use existing distinct verified disposable OS profiles, one live process per profile. Current qualification requires a signed-in rendered Windows desktop and unminimized game windows; environment redirection, private desktops and nominal process liveness do not establish support.
- Preserve closed sealed checkpoint sidecars and Games tree hashes for each profile. Read current generation/status instead of copying an old PID, epoch or request number. Do not reseed a running profile.
- Before foreground keyboard/mouse testing, establish current desktop availability. The user authorized the current session, and that authorization covered the recorded controls. The bounded vitals helper itself uses private worker IPC and exact-process recording; UI acceptance is separately timestamped.

## Repeatable bounded capture/replay

1. Build the bridge/host/control and run the focused HOST tests in `docs/testing.md`. Freeze source and payload hashes before launching. Use fresh evidence paths; retain every failure.
2. Run `tools/native/start-worker.ps1 -WorkerId 01 -M05Role Authority` and `-WorkerId 02 -M05Role Replica` as separate explicit native actions. These select isolated `--authority-probe` / `--replica-probe` modes; they do not alter normal Play. Read each current JSON under `local/worker-accounts` and verify actual role-ready and persistence-ready trace events.
3. Start exact PID/HWND WGC capture with `tools/native/capture-game.ps1`. Use `-AllowConcurrent` only for the explicitly selected original process when another recognized original game is also running. Inspect actual frames throughout loading and after application; a splash image plus HUD is not a view of native 3D gameplay. This recorder does not capture audio or measure native presentation timing.
4. Send `SporeMP.WorkerControl.exe GENERATION SUPERVISOR_PID load CURRENT_EPOCH` through the existing private IPC. `accepted` queues a load; require the native load-complete event, live Creature epoch and persistence state 6. Adopt exact saved A/B nouns from the verified checkpoint sidecar. `tools/native/adopt-loaded-actors.py WORKER_ID --sidecar local/SEALED_SIDECAR.json --output local/FRESH_ADOPTION.json` records that bounded adoption without a second load or any spawn. Require `checkpoint_restore` with `valid:true`, matching IDs and `created_nouns:0`.
5. Run `python tools/native/replica-probe.py capture --worker 01 --output FRESH_SOURCE.json`. The source must be an actual traced living-avatar sample, with matching build/process/generation, complete native prefix and hash. The helper samples native state; it does not establish which native action caused it.
6. Run `python tools/native/replica-probe.py replay --worker 02 --source FRESH_SOURCE.json --baseline 1 --challenge --output FRESH_REPLAY.json`. A higher fresh baseline is required if the same process has admitted one already. The helper validates source evidence before sending begin/bind/apply, duplicate, native challenge, audit, disconnect, another native challenge, post-disconnect apply and forbidden source-publication requests. Review exact command exits and trace outcomes.
7. Require one matching native application, a visible changed value when applicable, unchanged values over intervening updates, duplicate `stale`, post-disconnect `invalid`, and publication `unavailable`. Compare original AI/damage/reward events and per-domain counters. Unexercised or unhooked domains remain NOT RUN. Do not call zero DNA a nonzero reward test.
8. Finish owned recordings, send bounded shutdown with the current generation/epoch, and observe actual game/supervisor exits. Validate trace sequences, QPC, engine thread, healthy detach and loaded payload hashes. Recheck personal hashes and closed disposable checkpoint trees. Archive diagnostics; keep game binaries, saves and raw game media ignored.

The current .29 receiver may reuse an original .16–.28 authority sample with the same validated scalar capture ABI. The current nonzero reward source is the retained .18 native combat run. Do not regenerate native actions merely to make version labels match.

For a long disconnected check, record the actual disconnect QPC/UTC, keep the same original process running, and call replica opcode 7 with the current generation and scene before admitting a higher baseline. Require unchanged source DNA/vitals at the end of the interval, another successful native denial challenge, and then absolute fresh-baseline replay without a second grant. Record actual duration; nominal waits or process liveness alone are not native acceptance. The .18 replica failed at a population factory caller after its short probes; preserve the crash and compare the corrected run against that interval. Close and archive every process before checking checkpoint/personal hashes.
