## Commands and decisions

Open the native console with Ctrl+Shift+C. A fresh setup usually assigns A=1, B=2; always read actual IDs. After retirement or reload, use new IDs. Prefix every line below with `sporemp_actors`.

| Command | Behavior |
|---|---|
| `setup` | Bind the live local avatar to owner 1; create one native same-species creature with native herd/context for owner 2. Reject a second live pair. |
| `players` / `players off` | After live A/B setup, create or retire B's native cPlayer and record native state. Two create/remove generations pass in player-02, including final bridge disposal. This does not initialize the Creature stage or enable rewards. |
| `rewards` | After setup and players, initialize the audited B native stage/award counter for the same-species brain-level-zero fixture. Original DNA/goal/combat and deferred display processing pass in award-01; full stage initialization and brain advancement do not. |
| `status` | Show A/B/epoch and trace health; sample native values. |
| `jump OWNER ACTOR` | Queue one native `DoJump(0)` request. Queue `accepted` is not native action acceptance. Require the JSON native return and matching delayed landing. |
| `move OWNER ACTOR forward/right/back/left` | Request a six-unit native WalkTo in the actor's local direction. Original collision/AI remains active. |
| `approach OWNER ACTOR TARGET` | Request one native WalkTo to the live target's current position. No auto-chase or attack is implied. |
| `attack OWNER ACTOR TARGET` | Set native creature target and request original default attack ability. Return from PlayAbility does not prove a hit. |
| `engage OWNER ACTOR TARGET` | Hold one owner-checked intention for at most 30 seconds. Every due step resolves current identities, requests native approach or attack using native range/footprint values, and respects native active/recharge bits. Native hit/damage/reward calculations remain authoritative. |
| `duel OWNER` | Create one fully initialized foreign native NPC 1.5 units ahead of the owned actor and queue one owned attack in that update. It neither forces NPC attacks nor applies damage. |
| `opponents` | Create one foreign native NPC near A and one near B using a live template. |
| `npc NPC TARGET` | Developer fixture action: set an owner-0 NPC's native target once; its original AI chooses subsequent behavior. Not a client-authorized command. |
| `stop OWNER ACTOR` | Cancel the actor's held intention and clear its native creature combat target. It does not cancel every movement/AI goal. Active cancellation is implemented but not yet natively qualified. |
| `retire OWNER ACTOR` | Destroy a live non-avatar actor through the native noun manager. The local avatar and already-dead actors cannot be retired this way. |
