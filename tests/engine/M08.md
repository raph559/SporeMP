## First increment commands

Run in PowerShell from the repository root. Sources must be closed files from reviewed
private backups; output paths must be fresh. Example paths/key below are illustrative,
not an observed creation or import authorization.

```powershell
python -m unittest discover -s tests/unit -p test_spore_content.py -v
ctest --test-dir build/win32 -C Release -R tooling_unit --output-on-failure -V
python tools/content/spore_content.py inspect local/example/EditorSaves.package --output local/m08-content/editor-before.json
python tools/content/spore_content.py compare local/example/EditorSaves.package local/example-after/EditorSaves.package --output local/m08-content/editor-diff.json
python tools/content/spore_content.py compare-trees local/example-before/source-0 local/example-after/source-0 --output local/m08-content/profile-diff.json
python tools/content/spore_content.py quarantine local/example-after/EditorSaves.package --key '40626200!12345678.2b978c46' --output local/m08-content/candidate.json
```

Exit 0 means the offline operation succeeded; comparison mismatch returns 20;
malformed/unsupported/unsafe input or I/O failure returns 2. Reports retain native
validation NOT_RUN and readiness false. Nothing launches SPORE or installs content.
