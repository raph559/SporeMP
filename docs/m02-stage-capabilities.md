# M02 stage capability inventory

This is an early source inventory for all five required stages. It preserves the full mechanic coverage in `feature-coverage.csv` and does not certify complete adapters. M02 acceptance is VERIFIED for the recorded Creature jump/landing, console and scene reload paths; other stage-specific runtime tests remain **NOT RUN**. The source paths use the SDK commit and executable identity in `m02-binding-registry.md`.

Shared App mode messages do **not** prove save/load interception or all stage-local scene lifecycle events. `Simulator::cSimulatorSystem` declares virtual `Write(ISerializerStream*)` / `Read(ISerializerStream*)` in `Spore/Simulator/SubSystem/SimulatorSystem.h`; these declarations are not an atomic save or checkpoint API. Native save/load entry/outcome hooks remain TODO pending actual call-site/context verification. M09 durability and M17 transitions remain mandatory.

Damage/death events, inventory transactions, native progression changes, full stage action coverage and their reusable gameplay fixtures remain the conditional M02 tracing backlog as their bindings become verified. M02 acceptance requires at least one complete original action and explicit unknowns; its verified baseline does not qualify these remaining mechanics. They are still mandatory before the corresponding M03 and M11–M17 native acceptance. Sampled health/hunger/dead fields are observations, not substitute event coverage. The accepted probe and this remaining list are tracked separately; none of these requirements was deleted or demonstrated by the jump fixture.
