## Identity and execution contract

Every address below is a preferred-base VA for GOG Galactic Adventures 3.1.0.29, original executable SHA-256 `dc04aee5a3debc3f1ad4c1a937460e99a29b9bd3bc285008be83615dd5e59a37`, preferred image base `0x400000`. The implementation converts these to RVAs against the actual loaded module. SDK commit: `cbf9206b9a823f0911cd9be0217104a49d72380b`; injector commit: `26adca9a2578b5bb32ba2eac90d96bd9ac7d48a9`. Unknown executable/content/payload identity is rejected by NativeHost before injection. The SDK label is provenance, not independent ABI proof.

All mutation calls, native census resolution and projection execute on the verified engine thread, outside loader lock. Wrong-thread replica calls are denied and counted. Authority remains the original native simulator. Hook installation is all-or-nothing through a Detours transaction after entry-byte/vtable checks. Disposal retains the role through callback cleanup; unhooking itself ends interception. The observed clean exits and file hashes bound teardown claims.

`native_replica.cpp` contains the exact runtime prefixes, including 14-byte checks for new paths. `native_replica_abi.h` contains the checked conventions. Ghidra 12.1.3 / JDK 21.0.12.1+1 exported actual x86 instructions and decompiled bodies; [research provenance (archived)](public-evidence.md#historical-artifacts "Original path: evidence/2026-09-13-m05-completion/research-provenance.json") hashes 83 retained exports. Raw decompiled bodies stay under ignored `local/m03-static`. The static manifests/indexes and exact reproduction commands are archived under the session's `static/` directory. Exported inferred C types must be checked against stack cleanup, register use and callers.

## Diagnostic trace budget

The .20 replica passed its five challenges, including the longer disconnection and fresh baseline, but then exhausted the **32 MiB** M03 trace budget. Observation failure produced a status with zero AI progress; the supervisor terminated the owned job with `regressed_native_progress` and exit 35 before the explicit shutdown reached it. The retained trace is **33,552,875 bytes**, with no healthy close. This is a diagnostic-limit failure, not another population access violation or a clean run.

Build **0.0.21** retains the same file bound and counts every intercepted call. Full cumulative counter summaries are now emitted every **5 seconds**, plus forced snapshots for commands and disposal; projection comparisons and their audit records are unchanged. If the trace budget is exhausted, a reserved terminal `trace_limit` record identifies `diagnostic_budget_exhausted` before observation is disabled. Failed status preserves already counted progress, and the supervisor recognizes `engine_reported_failure` before its regression check. The new real-pipe/child-process HOST regression passes as part of **189** worker assertions. The terminal trace-limit record itself has not been separately triggered in original SPORE on .21; the final native soak verifies the reduced log growth and normal shutdown below the unchanged bound. This remains a bounded developer trace, not indefinite production logging.

## Remaining split points and reproduction

The crash reproduction is: run .18 in the prepared worker-02 OS profile, load/adopt the sealed Creature fixture, apply the captured authority sample, disconnect, and allow native timers to continue. At about six minutes after the first apply, a population routine calls the denied factory and dereferences EAX=0. Expected: no locally created authoritative creature, no crash. Observed: access violation `C0000005` at original-image RVA `94F86D`, then `C000041D`; final game exit `3221226525`. The dump's engine thread and register context agree with the static instruction `MOV EAX,[EAX+B4C]` immediately after the factory call. The dump parser's raw stack scan is not a reliable unwound call stack. Raw dumps remain private under ignored `local/m05-completion/crash-replica-01` with hashes in research provenance.

The corrected .19 result is a clean 461.958-second post-apply run, with no avatar vitals drift and denial retained across a fresh baseline. This bounds the observed fix; it does not prove all potential factory callers null-safe. Known other callers include different herd, initialization, stage and event paths listed in the archived index. The adapter currently admits only the living Creature avatar, and unsupported modes/campaign transitions are not accepted M05 fixtures.

`C19900` is separable from presentation and is guarded. `C1E8B0` is not: it drives self movement/animation and creates effects/projectiles as well as mutations. The charge/no-attack slices are now implemented as recorded above; only bite cleanup and marked timer fixtures have current native evidence. C0FE30's projectile result is dereferenced unchecked by its caller, so denying that factory by returning null is not a valid implementation. A charge/spit-capable fixture and effect-lifetime investigation remain prerequisites for admitting those abilities; no blanket Animal Update suppression is allowed.

Charm expiry is split as above, and the actual foreign-species callback now has native/UI evidence. `D38150` builds/caches a species mission through original noun creation and C30320 after selection; the resulting description is not proof of completed social progression. Natural consumption, other outer Strategy actions, pending effects, full relationship/progression state and native replica death/reuse remain NOT VERIFIED. Actual ordinary saved-world Play is now denied before UI mutation; other unlisted load paths are not thereby qualified. Feature admission boundaries are retained in the acceptance decision.

No local movement prediction is enabled. New prediction must use proven reversible state and must never replay a reward, grant, spawn or progression handler. Motion snapshots/interpolation and reliable object lifecycle transport belong to M06 after M05's acceptance gate.
