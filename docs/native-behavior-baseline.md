## Baseline method

For every mechanic, record identical initial fixture/content where possible, native entry path, player/faction context, pre/post native state, authoritative owner and relevant timers. Separate observations made by engine hooks from events emitted by the mod. Trace object destruction and generation changes to find invalid pointers.

Compare a native run with observational instrumentation, then the authoritative/replica version. Assert stable IDs and authoritative values, not pointers or animation pose equality. Use RNG equality only when controllable and proven; otherwise compare invariants/distributions. Record multiplayer policy differences explicitly. M02 needs at least one complete original action trace, including unchanged native execution, before multi-actor claims begin.
