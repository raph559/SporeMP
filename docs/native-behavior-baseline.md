## Candidate bindings and remaining probes

- `App::cAppSystem::SetUserDirNames(const char16_t*, const char16_t*)`: source-declared virtual member, x86 thiscall, cAppSystem size assertion 0x1F0; header and `AddressesApp.cpp` binding exist. Early call timing and all downstream writes remain unknown. Do not patch fields or guess an address.
- `Resource::Paths::GetDirectory(PathID, eastl::string16&)`: read-only path inspection candidate in `Spore/Resource/Paths.h`; relevant IDs include AppData, Games and Preferences. Invocation requires a valid initialized resource context.
- `Simulator::cGameNounManager`: avatar/player/tribe/civilization state and active-noun enumeration candidates. Single-player-oriented fields are a context risk, not evidence of multi-player support.
- `Simulator::cCreatureAnimal::Create`: candidate actor creation path. NPC/avatar AI tick hooks were observed in the first M02 trace; they do not provide a remote controller or safely disable duplicate simulation.
- `Simulator::cCombatant` and `cCombatSimulator`: trace native action execution through outcome; setting health is not acceptable proof.
- `Simulator::cPlanetRecord`: persistent records differ from visible planet models; no arbitrary snapshot import/export or save merge is assumed.

## Baseline method

For every mechanic, record identical initial fixture/content where possible, native entry path, player/faction context, pre/post native state, authoritative owner and relevant timers. Separate observations made by engine hooks from events emitted by the mod. Trace object destruction and generation changes to find invalid pointers.

Compare a native run with observational instrumentation, then the authoritative/replica version. Assert stable IDs and authoritative values, not pointers or animation pose equality. Use RNG equality only when controllable and proven; otherwise compare invariants/distributions. Record multiplayer policy differences explicitly. M02 needs at least one complete original action trace, including unchanged native execution, before multi-actor claims begin.
